💡 Min-Heap of Size K logic
  • The Top-K Problem: To retrieve the K largest elements from an infinite stream, we maintain a Min-Heap of size K.
  • Root is Threshold: In a Min-Heap, the root node holds the absolute minimum value in the heap. This root acts as the "barrier of entry" for our top-K elements.
  • Ignorability: Any incoming element with a score $\le$ Root can never be in the top-K list and is instantly ignored in $\mathcal{O}(1)$ time.
  • Swapping: If an incoming element has a score $>$ Root, it qualifies. We eject the root and put the new element at the root.
  • Sifting Down: After swapping, the heap property is violated. We sift the root down in $\mathcal{O}(\log K)$ time to restore order.
