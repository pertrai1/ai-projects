⚙️ Kahn's Algorithm Steps
  1. Calculate the In-degree (number of incoming edges) for every vertex in the graph.
  2. Identify all vertices with an In-degree of 0 and insert them into a Queue.
  3. Pull a vertex from the front of the queue and append it to our sorted results.
  4. For each outgoing edge from this vertex, remove the edge and decrement the in-degree of its neighboring node by 1.
  5. If a neighbor's in-degree hits 0, immediately insert it into the queue.
  6. Repeat until the queue is empty. If nodes remain on the board but the queue is empty, a Cycle has halted execution!
