# 10-minute AI training routine

## Minute 1, pick one real task

Choose something small but real:
- summarize an article
- draft an email
- debug a snippet
- brainstorm a feature
- analyze a decision

Use real work when possible. Practice sticks better there.

## Minute 2, make a prediction

Before asking AI, write down:
- my current guess:
- confidence 0 to 100:
- what AI will probably miss:

This is your calibration rep.

## Minutes 3 to 4, get a first answer

Prompt normally, but ask for structure:
- answer
- assumptions
- alternatives
- likely failure modes

You want more than a polished blob.

## Minutes 5 to 6, challenge it

Ask one of these:
- What would make this wrong?
- What is the strongest objection?
- What edge cases did you ignore?
- What would an expert criticize?

This is the most important part.

## Minutes 7 to 8, verify one thing

Pick just one:
- check the source
- run the code
- inspect the logic
- compare with docs
- sanity-check the numbers

Don’t verify everything. Verify something real.

## Minute 9, revise

Now decide:
- accept
- reject
- refine
- ask a better follow-up

The goal is not blind trust or blind distrust. It’s better judgment.

## Minute 10, log one lesson

Write one sentence:
- “AI was strong at X, weak at Y.”
- “I was too trusting when...”
- “Asking for edge cases helped.”
- “I should verify factual claims, not wording.”

That’s where compounding starts.

Weekly focus rotation

To keep it fresh:

- Mon: summarizing
- Tue: reasoning / planning
- Wed: coding / debugging
- Thu: writing / editing
- Fri: decision analysis
- Sat: creative exploration
- Sun: review patterns from the week

What success looks like

After a couple weeks, you should notice:
- you ask better first prompts
- you trust polished answers less
- you verify faster
- you catch more subtle mistakes
- you feel more confident without getting sloppy

If you do only one habit, make it this:

Before accepting any meaningful AI output, ask: “What would make this wrong?”
